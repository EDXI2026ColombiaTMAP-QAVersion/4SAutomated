# Deploy en Vercel

1. Importa este proyecto en Vercel como proyecto estático.
2. Haz un nuevo deploy.

El acceso se valida en el navegador y se mantiene durante la pestaña abierta mediante `sessionStorage`. Esta opción es adecuada para una barrera de uso interna, pero no debe considerarse seguridad fuerte: la clave está incluida en el JavaScript del sitio.
